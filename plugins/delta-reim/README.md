# Plugin delta-reim

Assistants de démarrage pour l'équipe Delta Reim, préparés par Legal Data Space pour la formation-action Claude.

- `fiche-synthese-bail` : fiche synthèse d'un bail commercial, chaque information avec son article source, et une liste
  de points à vérifier. Modèle de fiche dans `skills/fiche-synthese-bail/assets/`.
- `compte-rendu-reunion` : compte rendu de réunion à partir de notes ou d'une transcription, avec décisions, tableau des
  actions et points ouverts.
- `atelier-creer-assistant` : accompagne la création d'un nouvel assistant en quatre étapes (Décrire, Instruire,
  Nourrir, Éprouver) et produit le fichier à importer.

Ces assistants préparent un travail que l'utilisateur relit. Ils ne donnent pas d'avis juridique. Installation et
contact : voir le README à la racine du dépôt.
